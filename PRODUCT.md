# GotAll product direction

## Mission
Leave home without forgetting anything.

## Rule of zero friction
GotAll is normally used when the user is already leaving and may be late. Every interaction must reduce thinking and time. If a feature adds friction without helping memory, it does not belong in the core flow.

## Core experience
1. The user has a personal number representing the things they need before leaving.
2. The fastest entry point should be the home-screen widget or watch, not navigating through the phone app.
3. One item is presented at a time.
4. One tap confirms it and advances immediately.
5. Strong contrast, large targets, minimal copy, no visual distraction.

## Visual direction
- White background
- Black primary actions and typography
- Neutral greys only when hierarchy requires them
- No dark mode in the current roadmap
- Motion/haptics only when they reinforce confirmation

## Priorities
### v0.2
- Monochrome UI refinement
- Preserve the approved onboarding and core leaving flow
- Faster interaction and larger touch targets
- Prepare Android widget/deep-link architecture

### v0.3
- Android home-screen widget as a primary entry point
- One-tap I'M LEAVING launch
- Personal number visible on widget where platform architecture allows clean synchronization

### v0.4
- Wearable-first prototype
- Galaxy Watch / Wear OS
- Apple Watch after iOS base is ready
- One item at a time, tap to advance

## Future — deliberately not core yet
GotAll can eventually support contextual memory routines using the same interaction model: Gym, Grocery, Travel, Work and custom routines. These should not be introduced until the leaving-home habit is validated. The product should become a reusable memory trigger, not a complicated task manager.

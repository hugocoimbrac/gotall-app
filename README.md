# GotAll

GotAll is a minimal leaving-routine app built around one idea: **your number**.

Instead of behaving like a task list, GotAll lets you define the things you carry and check before leaving, then runs a fast one-by-one confirmation flow.

## Product principles

- Zero friction.
- One tap to start.
- The number is the heart of the product.
- The widget is the primary entry point.
- The watch should become the fastest trigger.
- The full app is mainly for setup and configuration.
- Minimal black-and-white interface.
- GotAll is not a to-do list or generic checklist app.

## Current Android MVP

- First-run onboarding.
- Personal carry/check items.
- Persistent configuration access from Home.
- Personal GotAll number.
- Leaving Mode with one-item-at-a-time confirmation.
- History.
- Responsive safe-area layout.
- Android home-screen widget.
- Widget deep-link directly into Leaving Mode.
- GotAll black-and-white launcher icon.

## Roadmap

1. Stabilize Android phone + widget experience.
2. Galaxy Watch / Wear OS companion experience.
3. iPhone version.
4. Apple Watch companion experience.
5. Store-release preparation and public beta.
6. Validate retention and usage before expanding monetization.

## Future profiles — planned, not current scope

GotAll can later support multiple personal contexts without becoming a task manager. Each profile owns its own items, number and one-tap entry point.

Examples:

- **I'm Leaving** — everyday essentials.
- **I'm Going to the Gym** — gym-specific items.
- **I'm Travelling** — travel essentials.
- **I'm Going to Work** — work-specific essentials.

The long-term interaction remains the same:

**one context → one number → one tap → confirm → done.**

Multiple profiles/widgets are intentionally deferred until the core phone, widget and watch experience is proven.

## Monetization direction

No disruptive advertising. Monetization should preserve the zero-friction core experience. A future premium tier may be evaluated for expanded capabilities such as multiple profiles/widgets, watch features or cross-device functionality, but this is not locked until the core product is validated.
